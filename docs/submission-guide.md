# FDE 面试材料投递说明

## 推荐发送方式

不要把所有内容只打成一个压缩包发送。在线 Demo 和 GitHub 应直接写在邮件正文中，简历与项目报告作为两个独立 PDF 附件，方便招聘团队在手机或电脑上直接预览。

演示视频原文件约 73 MB。MP4 已经是压缩格式，继续打成 ZIP 通常不会明显缩小，还可能触发邮件附件限制。因此视频优先上传网盘或对象存储，并把无需登录、长期有效的分享链接写进邮件；如果生成了小于邮箱限制的清晰压缩版，也可以同时作为附件发送。

## 邮件应包含的内容

- 在线演示：<https://armaygooser.site>
- GitHub：<https://github.com/armaygooser/duideshang>
- 演示视频：填写上传后的公开分享链接
- 附件一：`01_吴林斌_简历.pdf`
- 附件二：`02_对得上_项目报告.pdf`

不需要发送源代码压缩包，GitHub 已经承担代码交付和版本记录的作用。也不需要发送 Word 版报告；PDF 的版式更稳定，更适合正式投递。

## 发送前检查

1. 使用无痕窗口和手机网络分别打开在线 Demo、GitHub 和视频链接。
2. 确认视频链接不要求登录，或在邮件里清楚写出提取码。
3. 打开两个 PDF 附件，确认文件名、中文字体和页面完整。
4. 回复原面试邀请邮件，保留上下文，不另开主题。
5. 面试为 2026 年 8 月 12 日 15:00，材料最迟应在 14:00 前发出；建议 13:30 前完成发送。
6. 面试当天保留本地 Demo 作为在线服务异常时的备用方案。

## 是否发送压缩包

不建议把压缩包作为主要投递方式。当前目录中的“FDE面试提交材料”是自己的归档和发送清单；实际邮件以链接加独立 PDF 附件为主。只有对方明确要求统一打包时，再把不含大视频的 PDF 和说明文件压缩发送。
