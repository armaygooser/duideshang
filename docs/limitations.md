# 局限、风险与待验证假设

## 已实现但属于模拟数据

- 价格是为功能演示编写的门店内部价目，不是市场统一价格，也没有经过供应商核价。
- 材料规格、施工风险和验收模板用于展示可审计知识库的形态，正式商用前需由具体门店和施工负责人审核。
- 本地 Provider 是确定性的关键词/模式识别器，用来保证断网演示稳定；配置 DeepSeek 后可处理开放表达，但仍可能误解、漏项或输出无效结构。

## 产品局限

- 仅覆盖广告制作门店的门头询价，不支持其他行业、支付、签约、微信自动接入、多商户或复杂权限。
- 浏览器 localStorage 不是多人协作数据库；清理站点数据会丢失会话。
- 当前没有图片上传、现场测量、效果图合成、报价版本对比和审批工作流。
- 打印依赖浏览器打印为 PDF；尚未提供带电子签章的固定版式 PDF。
- 人工调整能力存在于后端契约，当前 UI 没有暴露，避免演示时随意改价。

## 风险

- 错误复尺、墙体承载、电气安全和审批条件无法仅靠文字工具判断，必须现场复核。
- 即便字段都已确认，客户对视觉效果仍可能有主观差异；商用需要带尺寸标注的最终效果稿或实物色样签字。
- 真实模型 Provider 可能产生遗漏或错误分类，因此结构校验、原文引用、人工确认和报价规则边界必须保留。
- DeepSeek Agent 的工具调用与结构化输出已通过模拟响应测试；由于仓库不包含用户 Key，交付验证没有产生真实模型费用，也不声称验证了线上可用率。

## 尚待验证的商业假设

- 客户是否愿意完成逐项确认，而不会觉得流程过长。
- 店员是否愿意维护内部价目和知识规则。
- 确认单是否能实际降低返工或争议。
- 哪些问题对成交率影响最大，哪些可以延后到上门复尺。

没有开展或虚构用户访谈、转化率、节省时间或商业效果数据。
